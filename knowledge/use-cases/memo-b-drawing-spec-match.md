## 対象

複数の PDF 図面・技術仕様書からテキストを抽出し、材質・仕上げなどの項目が文書間で一致するかを照合して一覧で返す。

## 前提

- 誰が使うか: 設計・開発部門の担当者
- データを外に出せるか: 未確認（自社データ基盤上で内製と公表。外部 API 可否は不明）
- 知識: 社内固有（図面と仕様書そのもの）。RAG ではなく入力そのもの。最新は不要
- ツール・書き込み: 書き込みなし。読み取りと突合のみ
- 合格線: 未確認（作業時間の削減は公表。見逃し率・誤検出率の線は未公表）

## 問われている問い

- PDF からテキストを取れなかった図面をどう扱うか（沈黙して「一致」と言わせない）
- 判定は生成にさせるのか、抽出だけさせて一致判定は決定的コードに置くのか
- 見逃しと誤検出のどちらを優先するか
- そもそも段を上げる必要があるか（1 パスで済む可能性）

## 近い既存 UC

- UC05。ただし「単一文書からの抽出」ではなく「文書間の一致判定」で、正解が決定できる点が違う

## 焼かない

社名、製品名、基盤の製品名、削減率の数値。
