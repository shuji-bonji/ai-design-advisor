# 設計判断レポート: UC23 投稿・レビューの判定

**対象**: 投稿・レビューがガイドラインに反していないかを判定し、対処すべきものを挙げる。
**前提**: 判定される相手は投稿者。データ外出は未確認。自動処分の有無は未確認。
**日付**: 2026-09-01
**型**: スキル完全出力（canonical 検証用）
**元**: [memo-k-ugc-moderation.md](./memo-k-ugc-moderation.md)
**位置づけ**: 確認論点。決定ではない。一貫性チェックであり、成否の検証ではない。

### 決まっていないこと

- データを外に出せるか
- 自動処分の有無
- 見逃しと過副検出のどちらを先に見るか

### ベンダーに確認してほしい論点

- 候補と処分を分けているか
- 異議経路があるか
- 投稿を信頼していないか
- 処分基準を断定していないか
- 許可判定をモデルに問っていないか

### いま言えること

- モデル: 分類は SLM
- パラメータ: Temperature 0 寄り
- 知識: ガイドラインは Skill / ラベル定義。本文は正本に載せない
- 実行系: 候補を挙げるまで。処分は permission
- Fine-tune: ラベルが稳で件数が多いときだけ疑う
- 権限: 判定が第三者の不利益になる。異議の経路が要る
- 測り方: 見逃しと過副検出を分ける。数値は持たない

- **推奨**: 候補まで。処分は人。異議受け口を置く。
