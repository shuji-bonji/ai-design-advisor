# UC で見えた穴（一覧）

UC01–23 の穴を一枚にした。

スキルの確度:

- **確定** … canonical があり、制約と衝突しない
- **条件付き** … 分岐がある（例: データを外に出せない）
- **情報不足** … 入力が欠けている、またはノート未精査

制約が分からないときは推測しない。`未確認` と書いて **情報不足** または **条件付き** で返す。

設問への起こし: [`../decision-axes/QUESTIONS.md`](../decision-axes/QUESTIONS.md)（A = 置かない、B = 作業済み）。
