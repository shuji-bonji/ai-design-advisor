# メモ: 融資稟議の担当者意見ドラフトと、後続プロセスの連鎖

- 日付: 2026-08-31

- 出所番号: https://prtimes.jp/main/html/rd/p/000000553.000067590.html

## 対象

行内の構造化データと非構造化文書（稟議添付資料・事務マニュアル）から担当者意見のドラフトを作り、契約・実行事務、モニタリング時の財務分析まで連ねる。

## 前提

- 誰が使うか: 融資業務の担当者。将来は同種の他組織へサービスとして提供予定と公表
- データを外に出せるか: 未確認
- 知識: 社内固有（過去の稟議・事務マニュアル）と出典（根拠の提示）
- ツール・書き込み: 事務作業の自動化を含む。承認の所在は未確認
- 合格線: 未確認（削減時間の見込みは公表。意見の質の線は未公表）

## 問われている問い

- 「意見」を生成させるのか、「論点と根拠の提示」で止めるのか（判断の主体は誰か）
- 過去の稟議を知識にすると、過去の判断の偏りを継承する。何を知識から外すか
- 3 プロセスを連ねるとき、段の数ではなく承認の位置をどこに置くか
- 自組織のデータが、外販されるサービス側に還流するか

## 近い既存 UC

- UC07 / UC02。UC12 とは表裏（調達する側ではなく提供側に回る）

## 焼かない

金融機関名、ベンダー名、年間削減時間の数値、業法・監督指針の条番号。
