# 設計判断レポート: UC16 契約書レビュー支援

**対象**: 契約書の条項からリスクを洗い出し、修正案を提示する法務の下ごしらえ。
**前提**: 誰が使うか未確認（社内法務か外部提供か）。相手方契約書の外出は未確認。書き込みなし想定。
**日付**: 2026-09-01
**型**: スキル完全出力（canonical 検証用）
**元**: [memo-d-contract-review-legal.md](./memo-d-contract-review-legal.md)
**位置づけ**: 確認論点。決定ではない。一貫性チェックであり、成否の検証ではない。

### 決まっていないこと

- 使用主体（社内か外部提供か）
- 相手方契約書を外部モデルに渡してよいか
- 出力は指摘までか修正案までか

### ベンダーに確認してほしい論点

- 引用が無ければ指摘しないか
- 適法断定を書いていないか
- 法律事務の代行になっていないか
- 学習利用を契約に書くか
- 条番号を仕様化していないか

### いま言えること

- モデル: 比較は LLM。外出不可なら D1 が勝つ
- パラメータ: Temperature 低め。Effort は比較ターンだけ
- 知識: 雛形と条項は RAG + Grounding
- 実行系: 修正案は人が採用。自律ループにしない
- Fine-tune: しない
- 権限: permission。出力が規制対象になりうる。適法断定はしない
- 測り方: 引用の有無。条番号は正本に載せない

### 詳細

- **推奨**: リスク指摘 + 引用までを初手にする。修正案は素案に留める。適法／違法は書かない。
- **なぜ**: 出力そのものが規制対象になりうる（legal-actors）。UC12 は契約に書く話。
- **代替**: 社内法務だけなら指摘のみ。外部提供なら主体と禁止を先に契約へ。
- **禁止**: 法令名を正本に載せる、適法断定、相手方文書を無断で社外モデルへ。
