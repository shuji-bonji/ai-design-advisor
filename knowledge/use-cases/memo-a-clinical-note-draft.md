# メモ: 診察中の会話音声からカルテ下書きを作り、電子カルテに渡す

- 日付: 2026-08-31
- 出所: 他社事例（報道）
- 出所番号: https://it.impress.co.jp/articles/-/28877
- 状態: ready
- 昇格: [uc13-clinical-note-draft.md](./uc13-clinical-note-draft.md)

## 対象

診察室の会話音声を文字化し、定型書式のカルテ下書きを生成して電子カルテへ渡す。

## 前提

- 誰が使うか: 診療中の医師（総合診療科・内科系）
- データを外に出せるか: 出せない。院内オンプレミスで処理を完結させると公表
- 知識: 出典（記載書式）と社内固有（院内の記載規約）。最新は不要
- ツール・書き込み: 電子カルテへ連携。下書きは医師が確認・修正して確定
- 合格線: 未確認（診察1件あたりの所要時間短縮は報告があるが、下書きの正しさの線は未公表）

## 問われている問い

- 音声認識の誤りと生成の誤りを、どこで分けて測るか
- 起案者と承認者が同一（医師）のとき、HITL は何を担保しているのか
- 要配慮個人情報を含む音声を、閉域内でどこまで・いつまで残すか
- 患者の同意と、会話に混ざる第三者の発話

## 近い既存 UC

- UC06 / UC07 / UC08 の重なり。ただし「起案者＝承認者」は UC02・UC09 の前提と違う

## 焼かない

病院名、製品名、短縮率の数値、「オンプレ以外は不可」という一般化。
