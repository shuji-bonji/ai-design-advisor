# 設計判断レポート: UC19 全件生成（人が全件を見ない）

**対象**: 商品ページなどの記載を全件対象に生成・補完する。人が全件は見ない。
**前提**: 公開面への反映がありうる。データ外出は未確認。合否の線は未確認。
**日付**: 2026-09-01
**型**: スキル完全出力（canonical 検証用）
**元**: [memo-g-bulk-generation.md](./memo-g-bulk-generation.md)
**位置づけ**: 確認論点。決定ではない。一貫性チェックであり、成否の検証ではない。

### 決まっていないこと

- データを外に出せるか
- 再現が要件か
- 巻き戻しの主体
- 合否の線

### ベンダーに確認してほしい論点

- 先落としの条件があるか
- 巻き戻し経路があるか
- 全件を最大モデルで回していないか
- 全件目視を仕様に書いていないか
- 削減時間を品質の代わりにしていないか

### いま言えること

- モデル: 定型は SLM
- パラメータ: 再現が要るなら Temperature 0 寄り
- 知識: マスタは入力そのもの。RAG とは限らない
- 実行系: バッチ。エージェントにしない
- Fine-tune: しない
- 権限: 公開は permission。巻き戻し経路が要る
- 測り方: 抽き取りまたは機械の先落とし。全件目視を前提にしない

### 詳細

- **推奨**: UC04 の「人が採用して公開」が成立しない。合否は抽き取りまたは機械。巻き戻しを先に置く。
- **なぜ**: 採用の責任が消えない。見ないだけで壁が外れるわけではない。
- **代替**: 危険項目だけ人が見る。
- **禁止**: 全件目視を仕様に書く、削減時間を品質の代わりにする。
