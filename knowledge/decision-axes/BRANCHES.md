# 典型分岐（UC01–23 から）

新規案件は作らない。既存 UC とスキル Step 3 の衝突解消だけを並べる。
チェック項目の ID は [CHECKLIST.md](./CHECKLIST.md)。

空欄のまま分岐を確定しない。

---

## 入力が先に勝つ

| 条件 | 先に動く軸 | 見本 |
| --- | --- | --- |
| データを外に出せない | D1 が勝つ。他次元をクラウド前提で組まない | UC06 |
| 画像・音声が本質 | D1 で Multimodal の要否。テキスト化で足りるなら載せない | UC08, UC14, UC18 |
| 書き込み・課金・個人情報更新がある | D6 を上げる前に D8 の承認 | UC02, UC09 |
| 待たせられない | D1・D2 が先。Effort を上げない。Agentic RAG に進まない | UC18 |
| 人が全件を見ない | D9。抽き取りまたは先落とし。全件 HITL を前提にしない | UC19 |
| 出力が第三者に作用する | D8。異議経路。自己判定で閉じない | UC23 |
| 合格の線が無い | 次元表は空欄を残す。一意に決めない | 全 UC の未確認 |
