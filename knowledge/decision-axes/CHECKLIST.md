# チェック項目（canonical の投影）

スキルと Web が同じ問いを使う。根拠は canonical。ここへ判断文を足さない。

答えは現場が埋める。空欄は推測しない。

| 空欄時の返し | 使うとき |
| --- | --- |
| 情報不足 | 入力が無い、またはノートが数値・手法・法令を置かない |
| 条件付き | 分岐がある（出せないなら D1 が勝つ、など） |
| 確定 | 制約が分かり、canonical と衝突しない |

入力の取り方はスキル Step 1 と同じ。深掘りの種は [`../canonical/_field-questions.md`](../canonical/_field-questions.md)。
