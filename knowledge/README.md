# Knowledge Base

このディレクトリは、設計判断の根拠となる知識を整理するための場所です。

## 構成予定

- `zenn-glossary/` … 『サクッと始める生成AI用語集』の主要章をMarkdownで保存
- `primary-sources/` … OpenAI / Anthropic / Google などの公式ドキュメント抜粋・リンク
- `decision-axes/` … 意思決定の軸（チェック項目）の定義
- `use-cases/` … 代表的なユースケース一覧と、各ケースで生じる判断ポイント

## 収集方針

1. Zenn用語集を軸に概念マップを把握する
2. Temperature / Reasoning Effort / SLM vs LLM / RAG / Agent などの推奨値やトレードオフは、可能な限り一次情報（公式ドキュメント）で裏取りする
3. 実務で見られるユースケースから帰納的に「本当に聞かれる軸」を抽出する
