# モデルクラス（LLM / SLM / Reasoning Model）

出典の中心: Zenn 用語集 第1部

## LLM（Large Language Models）

テキスト特化の大規模モデル。汎用性が高く、複雑な指示追従や創造的タスクに強い。
コスト・レイテンシ・インフラ要件は相対的に大きい。

## SLM（Small Language Models）

軽量・高速・低コストな小規模モデル。
- オンデバイスやエッジでの動作に向く
- 特定タスクに特化させると高い性能を発揮する場合がある
- 汎用性や深い推論ではLLMに劣ることが多い

選定の目安（実務的な観点）:
- プライバシー重視・低レイテンシ・高頻度・コスト制約が強い → SLM寄り
- 複雑な推論・多様なタスク・高い指示追従が必要 → LLM寄り

## Reasoning Model

じっくり考えてから答える新世代モデル。内部で思考過程を持つ。
Reasoning Effort で思考量を制御できる。
複雑な問題解決、エージェント的な多段推論、正確性が重要なタスクで有利。

## 選定の基本軸（後で decision-axes に落とす）

- タスクの推論深度
- レイテンシ許容
- コスト感度
- プライバシー / オンデバイス要件
- 知識の鮮度（カットオフ問題）
