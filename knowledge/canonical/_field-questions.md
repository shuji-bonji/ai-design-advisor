# 実務インタビュー設問との対応

現場で「AI使ってます」を深掘りするときに出る問い。実装エンジニアには当たり前でも、**なぜそうするか**が設計指針そのもの。

出典の例: @voidwarriorchan の深掘り設問（2026-08、X Article および続報）。一次情報ではない。**問いの粒度**をチェックリストの種として使う。

| 設問の核 | 対応次元 | 既に canonical にあるか |
| --- | --- | --- |
| 長いプロンプト以外のコンテキスト設計 | D3 D4 | あり（予算・住所分解） |
| 履歴の削り・優先 | D3 | あり |
| プロンプトキャッシュ / セマンティックキャッシュ | X / D9 | **今回追加** serving-and-cache.md |
| 遅さの切り分け（prefill vs decode） | X / D9 | **今回追加** |
| 量子化してよいか | D1 | selection.md に段を追加 |
| モデルとコードの責任分離 | D6 D8 D9 | あり（Hooks、permission） |
| 更新され続ける文書（分割・検索・rerank・ACL・削除） | D5 D8 | when-and-how.md に運用を追加 |
| 変更で品質が落ちていないか | D9 | あり |
| LLM-as-Judge をどこまで信じるか | D9 | あり |
| モデル障害時の縮退 | X / D9 | serving-and-cache.md |
| Temperature / Effort | D2 | あり |
| SLM vs LLM | D1 | あり |

完成後のスキル／チェックリストは、この種の「面接問」を **ユースケースに合わせて生成**できる。採用スクリーニングそのものが目的ではないが、ベンダー依頼前の社内点検と同じ形になる。
