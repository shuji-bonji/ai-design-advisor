# 持って行ける一枚

業務側が打ち合わせに持って行く紙。スキル完全出力の HTML 化ではない。Web アプリでもない。

Issue #2 の案 1。比較実行（[`../use-cases/COMPARE.md`](../use-cases/COMPARE.md)）のあと。

正本ではない。スキルはここを読まない。判断文・数値・製品名・法令を足さない。

## 三段

| 段 | 載せるもの | 載せないもの |
| --- | --- | --- |
| 決まっていること | 入力で確定した制約 | 推奨スタック、確度、次元名 |
| 決まっていないこと | 情報不足。発明しない | 目安の数字で埋めた穴 |
| ベンダーに確認すること | 問い | 「これを実装せよ」 |

スキルの「いま言えること」はこの一枚の一段目にしない。指示として読まれる。

## 落とし方

1. 完全出力が先。一枚から推奨を作らない
2. 「決まっていること」は対象と前提の文だけ
3. 「決まっていないこと」は完全出力の同項を、内部語彙を外して写す
4. 「確認すること」はベンダー文。段名・確度・焼かないは使わない
5. 新しい UC を一枚のために作らない
