# 安定コーパスの取込

understanding-llm / ai-agent-architecture に追加や改訂があったとき。自動で折り込まない。

## 順

1. 何が増えたかを見る（パスと一文）
2. 本ツールの範囲か問う
   - プロダクト設計の判断（D1–D9 + X）→ 候補
   - DEV（AIDD / Vibe / ワークフロー / Claude Code 手順）→ 入れない
   - 数値・モデル名・製品パス→ 入れないかヒューリスティック
3. 入れるなら INDEX に行を足し、対応 canonical ノートだけ直す
4. スナップショット SHA を README に書き換える
5. 入れないなら INDEX の「見送り」にパスだけ残す
